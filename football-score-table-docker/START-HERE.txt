Football Score Table — how to host this
=======================================

You need Docker installed. Nothing else (no Node, no npm, no browser setup) —
the app, Node and headless Chromium are all inside the image file.

Keep all three files in the same folder, then run:

    docker load -i football-score-table.tar.gz
    docker compose up -d

  (Two commands, that's it. No need to unzip the .gz first — docker load reads
   it compressed. The first one takes a minute or two.)

Open the site at:

    http://localhost:8080              from the machine running it
    http://<that-machine-ip>:8080      from anywhere else on the network

Everyday commands:

    docker compose logs -f     watch the logs
    docker compose restart     restart it
    docker compose down        stop it

To serve it on a different port, change "8080:8080" to e.g. "9000:8080"
in docker-compose.yml, then run `docker compose up -d` again.

IMPORTANT — if the match list comes up empty:
Sofascore blocks many datacenter/office IP addresses, so the app gets no data.
That is a network issue, not a broken build. See DOCKER.md ("If the match list
is empty") for how to confirm it in the logs and how to route around it with a
proxy.

DOCKER.md has the fuller details.
